## Question

AI Markdown Formatting (§14): AI จัดโครงสร้างเนื้อหาให้ผู้ใช้ทำอะไรได้บ้าง (เช่น เติมหัวข้อ จัดรายการ) โดย Block เป็นหน่วยจริง (006) "รักษาโครงสร้างเดิม" ตรวจอย่างไร: Block ไหนห้ามแตะ (Reference Card, ไฟล์, Code Block), ผลลัพธ์ของ AI ต้องผ่านผู้ใช้ยืนยันก่อนใช้ไหม และยกเลิกย้อนกลับได้ไหม

Options (Proposed, unconfirmed):
- AI เสนอฉบับใหม่ ผู้ใช้เทียบและยืนยันก่อนแทนของเดิม
- Reference Card, ไฟล์, Code Block ห้าม AI แก้
- ข้อความเดิมของผู้ใช้ต้องไม่ถูกลบหรือเปลี่ยนความหมาย

## Resolution

ยืนยันโดยผู้ใช้

- AI ทำได้กว้าง: จัดหัวข้อ/รายการ/ชนิด Block, เรียบเรียงประโยค, สรุปย่อ (Q1 ข), เพิ่มเนื้อหาเสริม และแก้คำผิด (Q4)
- Reference Card, ไฟล์, Code Block, Link ห้ามแก้ ย้ายได้เฉพาะเมื่อจำเป็นและต้องไม่หายไป
- AI เสนอฉบับใหม่ ผู้ใช้เทียบกับฉบับเดิมและกดยืนยันก่อนแทน
- ระบบตรวจก่อนแสดงผล: Block ที่ห้ามแตะต้องยังครบและไม่ถูกแก้ ถ้าไม่ผ่านทิ้งผลลัพธ์และแจ้งผู้ใช้
- ข้อสังเกต: เมื่อ AI เรียบเรียง/สรุปได้ กฎ "ข้อความเดิมต้องอยู่ครบทุกตัวอักษร" ใช้ไม่ได้ ส่วนที่ตรวจด้วยระบบได้จึงเป็นเรื่องโครงสร้างและ Block ที่ห้ามแตะ ส่วน "ไม่เปลี่ยนความหมาย" (§14) ตรวจโดยผู้ใช้ตอนเทียบและยืนยัน
- เริ่มเมื่อผู้ใช้สั่งต่อ Note เท่านั้น ไม่ทำอัตโนมัติ
