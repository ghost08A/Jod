## Question

กฎของ Trash (§8): ลบ Parent แล้ว Child เป็นอย่างไร, กู้ Child เดี่ยวๆ เมื่อ Parent ยังอยู่ใน Trash ได้ไหม, กู้แล้ว Parent เดิมถูกลบไปแล้วจะวางที่ไหน, มีลบถาวรไหมและเมื่อไร, และ Reference Card ที่ชี้ไป Note ที่ถูกลบต้องแสดงอย่างไร

Options (Proposed, unconfirmed):
- ลบแบบทั้งกิ่งเสมอ กู้ทั้งกิ่ง
- ให้เลือกลบเฉพาะ Note นี้ (Child ย้ายขึ้นหนึ่งระดับ) หรือทั้งกิ่ง ตามที่ §8 ระบุ "ลบทั้งต้นไม้"
- Reference Card ที่ชี้ไป Note ใน Trash แสดงสถานะ "ถูกลบ" และกดไปเปิดดูใน Trash ได้

จาก 002: Note ว่างที่ Title ยังเป็นค่าเริ่มต้นถูกลบอัตโนมัติถาวร ไม่ผ่าน Trash (ข้อยกเว้น) ต้องรวมในกฎ Trash

## Resolution

ยืนยันโดยผู้ใช้ (ตามข้อเสนอทั้งหมด)

- ลบ Note ที่มี Child: ผู้ใช้เลือกได้ "ลบทั้งกิ่ง" (ค่าเริ่มต้น) หรือ "ลบเฉพาะ Note นี้" (Child ขึ้นไปอยู่ใต้ Parent ของมัน; ถ้าเป็น Root note ลูกกลายเป็น Root note)
- กู้ที่ Note แม่ของกิ่ง = กู้ทั้งกิ่งพร้อมกัน
- กู้ Child เดี่ยวๆ ขณะ Parent ยังอยู่ใน Trash ได้ → กลับมาเป็น Unplaced note
- กู้ Note ที่ Parent เดิมไม่มีแล้ว (ลบถาวร) → Unplaced note
- ลบถาวร: ผู้ใช้สั่งเองจาก Trash พร้อมยืนยัน ไม่มีกวาดอัตโนมัติ
- Reference Card ที่ชี้ Note ใน Trash: การ์ดยังอยู่ แสดงสถานะ "ถูกลบ" เปิดดูหน้า Trash และกู้ได้ / หลังลบถาวรแสดง "ไม่พบ Note นี้" ไม่มีปุ่มกู้
- Note ใน Trash เปิดดูได้อย่างเดียว แก้ไขไม่ได้จนกว่าจะกู้
- ข้อยกเว้น (จาก 002): Note ว่างที่ Title ยังเป็นค่าเริ่มต้น ถูกลบอัตโนมัติถาวร ไม่ผ่าน Trash
