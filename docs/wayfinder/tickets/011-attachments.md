## Question

ไฟล์แนบ (§15): ไฟล์เป็นของ Note เดียวเสมอหรือใช้ร่วมกันได้, แนบแล้วแสดงเป็น Block ในเนื้อหาหรือเป็นรายการแยกของ Note, ไฟล์ชีวิตเป็นอย่างไรเมื่อ Note ไปอยู่ใน Trash / กู้คืน / ลบถาวร / ถูก Merge (กฎเหล่านี้ตัดสินแล้วใน 004 และ 005), ชนิดและขนาดไฟล์มีขอบเขตไหม

Options (Proposed, unconfirmed):
- ไฟล์เป็นของ Note เดียว ตามไปกับ Note ใน Trash/กู้/ลบถาวร
- Merge: ไฟล์ของ A ย้ายไปเป็นของ B
- แนบเป็น Block ชนิดใหม่ในเนื้อหา

## Resolution

ยืนยันโดยผู้ใช้

- ไฟล์แนบเป็น Block ชนิด "ไฟล์" ในเนื้อหาของ Note จึงเป็นของ Note เดียว ตามไปกับ Note เมื่อ Trash / กู้ / ลบถาวร และเมื่อ Merge ไฟล์ของ A ไปกับเนื้อหาที่ต่อท้าย B
- ระดับ requirement: มีขีดจำกัดชนิด/ขนาดไฟล์ และบอกผู้ใช้ชัดเมื่อเกิน ตัวเลขตัดสินตอนออกแบบ Architecture
