## Question

ไฟล์แนบ (§15): ไฟล์เป็นของ Note เดียวเสมอหรือใช้ร่วมกันได้, แนบแล้วแสดงเป็น Block ในเนื้อหาหรือเป็นรายการแยกของ Note, ไฟล์ชีวิตเป็นอย่างไรเมื่อ Note ไปอยู่ใน Trash / กู้คืน / ลบถาวร / ถูก Merge (กฎเหล่านี้ตัดสินแล้วใน 004 และ 005), ชนิดและขนาดไฟล์มีขอบเขตไหม

Options เดิมก่อนตัดสินใจ (เป็นข้อเสนอ ไม่ใช่ผลลัพธ์ ผลลัพธ์อยู่ใน Resolution):
- ไฟล์เป็นของ Note เดียว ตามไปกับ Note ใน Trash/กู้/ลบถาวร
- Merge: ไฟล์ของ A ย้ายไปเป็นของ B
- แนบเป็น Block ชนิดใหม่ในเนื้อหา

## Resolution

ยืนยันโดยผู้ใช้

- ไฟล์แนบเป็น Block ชนิด "ไฟล์" ในเนื้อหาของ Note จึงเป็นของ Note เดียว ตามไปกับ Note เมื่อ Trash / กู้ / ลบถาวร และเมื่อ Merge ไฟล์ของ A ไปกับเนื้อหาที่ต่อท้าย B
- ระดับ requirement: มีขีดจำกัดชนิด/ขนาดไฟล์ และบอกผู้ใช้ชัดเมื่อเกิน ตัวเลขตัดสินตอนออกแบบ Architecture

- (อัปเดตภายหลัง 2026-10-18) Block รูปภาพ (`/image`) เป็น Block ชนิดแยก ไม่ใช่ Block ไฟล์ ไฟล์ภาพเก็บไว้จนกว่าจะปลอดภัยที่จะลบ ความหมายของ "ปลอดภัย" และขนาดไฟล์ภาพยังไม่ได้กำหนด ดู `docs/open-questions.md` (OQ-2, OQ-3) ไม่อนุมานรายละเอียดการจัดเก็บจากการตัดสินใจนี้

- (อัปเดตภายหลัง 2026-10-18) ตัดสินแล้ว: ไฟล์ภาพของ Block รูปภาพ ลบจริงเมื่อไม่มี Block ใดอ้างถึงแล้ว นับรวม Block ใน Note ที่อยู่ใน Trash, ฉบับก่อน AI แทน (Undo) ที่ยังเก็บอยู่ และ Note ที่ Merge ไปแล้ว ขนาดไฟล์ภาพยังไม่กำหนดตัวเลข (OQ-3) ที่เก็บไฟล์ใช้ S3 API ด้านหลัง Interface (ADR 0001)
