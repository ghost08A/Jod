## Question

ตัดสินใจ Architecture ที่ Product Design (ticket 001-022, `docs/product-spec.md`) ต้องการ โดยไม่เปลี่ยน Requirement หรือ Business Rule ที่ยืนยันแล้ว ticket เดียวนี้เป็นที่ติดตามทุกหัวข้อ ไม่เปิด ticket แยกต่อหัวข้อ เรื่องที่ย้อนกลับยากเขียนเป็น ADR ใน `docs/adr/` (เฉพาะที่เข้า 3 เงื่อนไขของ domain-modeling)

## ข้อจำกัดที่ตัดสินแล้ว (อย่าถามซ้ำ)

ดู product-spec หัวข้อ 15 และ ADR 0001-0003: กลุ่มเพื่อน ไม่เกินหลักพันบัญชี/หลักหมื่น Note ต่อบัญชี ต้องออนไลน์ใน v1 .NET 8 + React + Docker, TipTap, ที่เก็บไฟล์ผ่าน S3 API ด้านหลัง Interface, AI = Gemini gemini-3.5-flash-lite แบบตัวฟรี ฐานโค้ดเดิม: Web → Service → Domain ยังไม่มีฐานข้อมูล (EF Core ใน Jod.Service เมื่อฟีเจอร์แรกต้องใช้)
