## Resolution

ตัดสินแล้ว (2026-10-19) ทีละข้อ ที่เหลือยังเป็น Not decided:

- ฐานข้อมูล: PostgreSQL (ADR 0004)
- โครง Tree: แม่-ลูกตรงๆ (Parent + ตัวเลขลำดับในหมู่พี่น้อง) ไล่ด้วย recursive query Alias แยกตาราง (ADR 0004)
- เนื้อหา Block: 1 Note = เอกสาร JSON ก้อนเดียว + ตารางไฟล์อ้างอิง (ADR 0005)
- Undo: เก็บฉบับล่าสุดฉบับเดียวต่อ Note อายุ 30 วันแล้วลบเอง แก้เพิ่มหลัง AI จัดแล้ว Undo = แจ้งเตือน (ADR 0005)
- ตรวจบันทึกชนกัน: เลขเวอร์ชันต่อ Note ไม่มีข่าวสดข้ามแท็บ (ADR 0005)
- ล็อกอิน: ASP.NET Core Identity + Access token 15 นาที/Refresh token 30 วัน หมุนทุกครั้ง ประสานแท็บฝั่ง Client ลิงก์ยืนยันอีเมล 24 ชม. ขอใหม่ได้ 3 ครั้งต่อชม. ลิงก์รีเซ็ตรหัส 1 ชม. (ADR 0006)
- ส่งอีเมล: `IEmailService` + SMTP + Mailpit บน Docker ไม่มีบริการส่งอีเมลจริง ไม่ซื้อโดเมน ผู้ดูแลส่งลิงก์ยืนยัน/รีเซ็ตต่อให้เพื่อนด้วยมือตามขั้นตอนใน ADR 0007 คำถามค้างคือ OQ-6
- ที่เก็บไฟล์: SeaweedFS 4.48 เป็นตัวเลือกสำหรับ v1 และเป็นฐานพัฒนาจาก PoC (branch `prototype/seaweedfs-s3`, commit `c6f9eee`, โค้ดทิ้งไม่เข้า dev) ตั้งค่าความปลอดภัยตาม ADR 0008 เปิดไฟล์ผ่าน Backend ใน v1 (ADR 0001) **ยังมีเงื่อนไขก่อน Production** ที่ยังไม่ผ่านตามที่ระบุใน ADR 0001 และ 0008 ขนาดไฟล์ OQ-3: Not decided คำถามค้างเรื่องผู้รับ Share Link ดาวน์โหลดไฟล์: OQ-7
- การเรียก AI (ตัดสินแล้วบางส่วน 2026-10-19): ฝั่ง Service เรียก Gemini ผ่าน Interface แคบ 2 การทำงาน (เสนอที่วาง, เสนอชุดการเปลี่ยนแปลง) ด้วยไลบรารีทางการ `Google.GenAI` ไม่ใช้ streaming อ่านชื่อโมเดลจากค่าตั้งค่า และไม่ให้ชนิดข้อมูลของ Google หลุดออกนอกชั้น Service ชื่อ Interface ให้ผู้ใช้ยืนยันก่อนตั้ง ถ้าไลบรารีส่วน C# ใช้ไม่ได้ตามเอกสาร เปลี่ยนไปเรียก HTTP เองได้หลัง Interface เดิม
- ความลับ: ตอนพัฒนาเก็บคีย์จริงในไฟล์ `appsettings.Development.json` ซึ่ง gitignore และไม่ commit (แม่แบบ `appsettings.Development.example.json`) ห้ามใส่ความลับใน `appsettings.json` หรือไฟล์ตั้งค่าอื่นที่ยังถูกติดตามใน git ตอน Production ใช้ environment variables หรือระบบจัดการความลับ ผู้ใช้เป็นคนใส่คีย์จริงเอง ต้องใส่ `appsettings.Development.json` ใน `.dockerignore` ตอนทำ Dockerfile ยังค้างในหัวข้อการเรียก AI: โควตาและข้อผิดพลาด (ticket 015)
