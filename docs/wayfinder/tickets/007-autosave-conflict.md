## Question

Autosave (§1) ทำงานเมื่อไรในมุมผู้ใช้ (ทุกการพิมพ์/หยุดพิมพ์/ออกจากหน้า), ผู้ใช้เห็นสถานะ "กำลังบันทึก/บันทึกแล้ว/บันทึกไม่สำเร็จ" ไหม, และเมื่อ Note เดียวกันถูกแก้จากสองแท็บหรืออุปกรณ์ (§12 ในแอปเจ้าของคนเดียว) ผู้ใช้ต้องเห็นอะไรและเลือกอะไรได้บ้าง

Options (Proposed, unconfirmed):
- แจ้งเตือนว่าชนกัน แล้วให้เลือกเก็บฉบับไหนหรือเก็บทั้งสองฉบับ
- แจ้งเตือนอย่างเดียว ฉบับล่าสุดชนะ แต่เก็บฉบับที่แพ้ไว้ดูได้
- ล็อกการแก้ไขทีละแท็บ

## Resolution

ยืนยันโดยผู้ใช้

- Autosave เมื่อผู้ใช้หยุดพิมพ์ชั่วครู่ (ประมาณ 1 วินาที) และเมื่อออกจากหน้า
- แสดงสถานะ "กำลังบันทึก / บันทึกแล้ว / บันทึกไม่สำเร็จ" ถ้าไม่สำเร็จเนื้อหายังอยู่ในหน้าจอ ไม่หาย และลองใหม่ได้
- บันทึกชนกัน (เช่น เปิด Note เดียวกันสองแท็บ): แจ้งเตือนทันที ให้เลือก "ใช้ฉบับนี้ / ใช้ฉบับอีกแท็บ / เก็บทั้งสอง" เก็บทั้งสอง = อีกฉบับกลายเป็น Unplaced note ใหม่ ไม่มีฉบับไหนหายเงียบๆ
