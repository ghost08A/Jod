## Question

กฎของ Tree (§3) คืออะไรบ้าง: ย้าย Note ได้ภายใต้เงื่อนไขใด (ห้ามย้ายเข้าตัวเอง/ลูกหลานของตัวเอง?), ลำดับของ Child ในระดับเดียวกันมีความหมายไหม, Note ราก (ไม่มี Parent) ได้หรือไม่, ย้ายทั้งกิ่งพร้อม Child เสมอหรือเลือกได้

Options เดิมก่อนตัดสินใจ (เป็นข้อเสนอ ไม่ใช่ผลลัพธ์ ผลลัพธ์อยู่ใน Resolution):
- ย้ายทั้งกิ่งเสมอ ห้ามสร้างวงวน
- Child มีลำดับที่ผู้ใช้จัดเองได้ หรือเรียงตามเวลา/ชื่ออัตโนมัติ

## Resolution

ยืนยันโดยผู้ใช้

- ย้ายทั้งกิ่งเสมอ (Note พร้อมลูกหลาน) ไม่มีโหมดย้ายเฉพาะตัว
- ห้ามย้าย Note เข้าตัวเองหรือลูกหลานของตัวเอง ระบบบอกเหตุผลสั้นๆ
- ลำดับของ Child ในระดับเดียวกัน ผู้ใช้จัดเองได้ (ลากสลับ) Note ใหม่ต่อท้ายสุด
- ผู้ใช้วาง Note ไว้ระดับบนสุดอย่างตั้งใจได้ = **Root note** แยกจาก Unplaced note (ปิดคำถามค้างของ ticket 002)
- ย้าย Note ที่เคยมี Parent ออกมาระดับบนสุด ได้ และกลายเป็น Root note
- ความลึกไม่จำกัด (§3)
