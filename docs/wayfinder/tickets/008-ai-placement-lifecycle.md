## Question

วงจรชีวิตของ Placement Suggestion (§7): AI วิเคราะห์เมื่อไร (ทุก Note ใหม่ / ผู้ใช้กดเอง / ตามช่วงเวลา), Note ที่แก้ภายหลังวิเคราะห์ซ้ำไหม, Suggestion เสนอหนึ่งตัวหรือหลายตัว, ยืนยันแล้วเกิดอะไร (ย้ายทันที), ปฏิเสธแล้วเสนอซ้ำได้ไหม, Suggestion ค้างอยู่ได้นานแค่ไหน และ AI เสนอ "Parent ใหม่ที่ยังไม่มี" ได้ไหม

หลักที่ผู้ใช้ระบุไว้แล้วใน `requirement.md`: AI เป็นผู้แนะนำ ไม่ใช่ผู้ตัดสินใจแทนผู้ใช้

Options (Proposed, unconfirmed):
- ผู้ใช้กดขอเอง ไม่วิเคราะห์อัตโนมัติ
- วิเคราะห์อัตโนมัติเมื่อ Note ยังไม่จัดวาง และแสดงรายการ Note ที่มี Suggestion
- ปฏิเสธแล้วไม่เสนอที่เดิมซ้ำ

จาก 002: "ให้ AI จัดให้" ตอนกด Save = Unplaced note + Placement Suggestion รอผู้ใช้ยืนยัน

## Resolution

ยืนยันโดยผู้ใช้

- AI วิเคราะห์เฉพาะเมื่อผู้ใช้สั่ง (กด "ให้ AI จัดให้" ตอน Save หรือกดขอจาก Unplaced note ที่ค้างอยู่) ไม่มีโหมดอัตโนมัติในเวอร์ชันแรก
- เสนอ Suggestion ตัวเดียว
- เสนอได้เฉพาะ Note ที่มีอยู่ (รวม Root note) ไม่เสนอสร้าง Note แม่ใหม่ ถ้าไม่มีที่เหมาะบอกว่า "ไม่พบที่เหมาะสม"
- ยืนยัน → Note ย้ายไปใต้ Parent นั้นทันที (ต่อท้ายลูกเดิม) และออกจากพื้นที่ "รอจัดวาง"
- ปฏิเสธ → Note เป็น Unplaced เหมือนเดิม ระบบจำที่ที่ถูกปฏิเสธ ไม่เสนอที่เดิมซ้ำเมื่อขอใหม่
- Suggestion ไม่หมดอายุ ไม่วิเคราะห์ซ้ำอัตโนมัติ แก้เนื้อหาแล้วทำเครื่องหมายว่า "อาจล้าสมัย" ให้ผู้ใช้กดขอใหม่เอง
- Parent ที่เสนอถูกลบ (Trash) → Suggestion หาย Note เป็น Unplaced ปกติ / ถูก Merge → Suggestion ตาม Alias ไปที่ Note ปลายทาง
- แสดงใน "รอจัดวาง": Note ที่มี Suggestion มีเครื่องหมายชัด และกรองดูเฉพาะที่มี Suggestion ได้
