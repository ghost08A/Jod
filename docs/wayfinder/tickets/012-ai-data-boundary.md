## Question

เมื่อผู้ใช้สั่งให้ AI จัดวาง (008) ข้อมูลอะไรถูกส่งให้ AI บ้าง: เนื้อหาและ Title ของ Note ที่กำลังวิเคราะห์, Context (§13) ของ Note นั้น, และข้อมูลของ Note อื่น (Title/Context ของ Note ที่เป็น Parent ที่เป็นไปได้) ต้องส่งเพื่อให้ AI เลือกที่วางได้ ผู้ใช้ต้องรับรู้หรือยินยอมก่อนไหม, Note ที่ผู้ใช้ไม่อยากให้ AI เห็นมีได้ไหม

Options (Proposed, unconfirmed):
- ส่งเฉพาะ Title + Context + ข้อความบางส่วนของ Note ที่วิเคราะห์ และ Title + Context ของ Note ผู้สมัครเป็นแม่
- แจ้งผู้ใช้ครั้งแรกที่ใช้ AI ว่าข้อมูลถูกส่งออก
- มีเครื่องหมาย "ห้าม AI เห็น" ต่อ Note

## Resolution

ยืนยันโดยผู้ใช้

- ส่งให้ AI: Title, เนื้อหา, Context ของ Note ที่วิเคราะห์ + เฉพาะ Title กับ Context ของ Note ที่เป็นที่วางได้ (ไม่ส่งเนื้อหาเต็มของ Note อื่น)
- แจ้งผู้ใช้ครั้งแรกที่ใช้ AI และปุ่ม AI บอกชัดว่าจะส่งอะไร
- ไม่มีเครื่องหมาย "ห้าม AI เห็น" ในเวอร์ชันแรก เพราะ AI ทำงานเมื่อผู้ใช้สั่งเท่านั้น
