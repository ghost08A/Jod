## Question

หน้าแรกและการจดโน้ตควรหน้าตาและความรู้สึกอย่างไร ให้ "จดก่อน จัดทีหลัง" ทำงานจริง: จัดหน้าแรกอย่างไรระหว่าง Tree กับ "รอจัดวาง", ขั้นตอน Save 3 ทาง (AI / Root note / Unplaced) ขัดจังหวะการจดไหม, Note ว่างที่หายเองรู้สึกปลอดภัยไหม, Title เริ่มต้นและรายการที่ชื่อซ้ำอ่านออกไหม

คำถามที่ต้องเห็นของจริงก่อนตอบ (จากการคุยรอบ UX): กลุ่ม 1 ของรายการ UX ที่เอกสารตัดสินไม่ได้

## Resolution

ผู้ใช้เลือก **layout C (Focus)** และยืนยันทิศทางรวม (Product Decisions ไม่เปลี่ยน)

- โครงรวม: workspace แถบข้างซ้าย + canvas เขียนโล่ง Title และเนื้อหาอยู่พื้นเดียวกัน ไม่มีกรอบ/การ์ด/เส้นแบ่ง/แถบล่าง คลิกพื้นที่แล้วเขียนได้ทันที
- Layout C: แถบข้าง ~300px, เนื้อหา max ~600px ชิดซ้าย (ไม่อยู่กึ่งกลาง), Title ใหญ่ ~52px, เว้นด้านบนมาก
- ธีมมืดเป็นหลัก (dark neutral) แถบข้างโทนกลืนกับพื้นเขียน แยกด้วยโทนสีไม่ใช้เส้น Tree เป็นแถว navigation ไฮไลต์จางๆ ที่ Note ที่เลือก
- แถบข้างซ่อน/แสดงได้ (☰ / `Ctrl+\`)
- Note ใหม่: เคอร์เซอร์อยู่ในเนื้อหาทันที Title เป็น placeholder จางๆ
- การจัดวาง (AI / Root note / Unplaced / ย้ายไปใต้ …) เป็นปุ่มตัวอักษรเล็กๆ มุมขวาบนของ canvas เปิดเมนูลอย ไม่ขวางการเขียน เลือกแล้วเขียนต่อได้ AI ที่เสนอแล้วแสดงเป็น "✦ ใต้ …" ในจุดเดียวกัน
- "รอจัดวาง" เป็นหัวข้อในแถบข้างเดียวกับ Tree ไม่ใช่การ์ด Note ที่ไม่มีชื่อแสดงบรรทัดแรกของเนื้อหากำกับ

ยังไม่ได้ตัดสิน (ต้องดูตอนใช้จริง): ข้อความ Title เริ่มต้น (prototype ใช้ "Untitled"), ความสว่างของข้อความเนื้อหาในธีมมืด, เมนู `/` จริง

Prototype ทั้งหมด (3 layout) เก็บไว้ที่ branch `prototype/capture-home` (commit 37f5927) ไม่รวมเข้า dev
