## Question

"จดก่อน จัดทีหลัง" ในทางปฏิบัติ: Note ที่เพิ่งสร้างอยู่ที่ไหนก่อนมี Parent, ต้องมี Title ตั้งแต่สร้างไหม (§1 บอก Title ต้องมี), ค่าเริ่มต้นของ Title คืออะไร, และ "ยังไม่จัดวาง" เป็นสถานะที่ระบบรู้จักหรือเป็นแค่ Note ราก

Options (Proposed, unconfirmed):
- มีพื้นที่ Inbox แยก Note ที่ไม่มี Parent ทั้งหมดเป็น "ยังไม่จัดวาง"
- Note ใหม่เป็น Note ราก ไม่มีสถานะพิเศษ
- Title เริ่มต้นเป็น "Untitled" หรือ AI/ระบบเติมจากบรรทัดแรก

ตัดสินแล้ว: Unplaced note = Note ไม่มี Parent ที่ไม่ใช่ Root note (001, 003) ผู้ใช้วาง Root note ตั้งใจได้ (003)
ยังเปิดอยู่: Note ใหม่ที่เพิ่งจดอยู่ที่ไหนในหน้าจอ, ต้องมี Title ตั้งแต่สร้างไหม, Title เริ่มต้นคืออะไร

## Resolution

ยืนยันโดยผู้ใช้

- Unplaced note แสดงในพื้นที่ "รอจัดวาง" แยกจาก Tree เมื่อจัดวางแล้วออกจากรายการเอง
- สร้างได้ทันทีโดยไม่ต้องตั้งชื่อ Title เริ่มต้นเป็นข้อความคงที่ (ไม่เปลี่ยนเองตามเนื้อหา)
- ปุ่ม New note มีปุ่มเดียว อยู่ที่หน้าแรกเท่านั้น ไม่มีปุ่มนี้ตอนเปิดอยู่ใน Note
- สร้างด้วย New note → มีปุ่ม Save ให้เลือก 3 ทาง: ให้ AI จัดให้ / Save เป็นแม่ใหม่ (Root note) / ปล่อยเป็น Unplaced
- สร้างด้วย `/Note` → ไม่มีปุ่ม Save เป็นลูกของ Note แม่ทันที
- เนื้อหา Autosave ตลอด ปิดโดยไม่เลือก = กลายเป็น Unplaced (ปุ่ม Save เลือก "ที่วาง" ไม่ใช่ "เก็บหรือไม่เก็บ")
- Note ว่างเปล่าและ Title ยังเป็นค่าเริ่มต้น ถูกลบอัตโนมัติ หายถาวรไม่ผ่าน Trash (ข้อยกเว้นของ §8 ส่งต่อ ticket 004)
- "ให้ AI จัดให้" = Note เป็น Unplaced พร้อม Placement Suggestion รอผู้ใช้ยืนยัน/ปฏิเสธ (§7) รายละเอียดอยู่ ticket 008
