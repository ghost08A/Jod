## Question

ค้นหาและกรอง (§6) ทำงานอย่างไรกับ Tree: ค้นในชื่อ/เนื้อหาของ Note ได้ แล้ว "Filter ตาม Parent" รวมลูกหลานทั้งกิ่งหรือเฉพาะลูกตรง, Note ใน Trash ถูกค้นเจอไหม, Unplaced note ถูกค้นเจอไหม, ค้น Context ด้วยหรือไม่

Options เดิมก่อนตัดสินใจ (เป็นข้อเสนอ ไม่ใช่ผลลัพธ์ ผลลัพธ์อยู่ใน Resolution):
- Filter ตาม Parent รวมทั้งกิ่ง
- Trash ไม่ปรากฏในการค้นหาปกติ
- ค้นชื่อและเนื้อหา แต่ไม่ค้น Context

## Resolution

ยืนยันโดยผู้ใช้

- Filter ตาม Parent รวมลูกหลานทั้งกิ่ง
- ผลค้นหาปกติไม่รวม Note ใน Trash (มีตัวเลือกค้นใน Trash แยก) แต่รวม Unplaced note
- ค้นเฉพาะ Title และเนื้อหา ไม่ค้น Context
