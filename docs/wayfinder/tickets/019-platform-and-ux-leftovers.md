## Question

เรื่อง UX/แพลตฟอร์มที่ยังไม่ได้ตัดสินหลังปิด prototype 017 และ 018: ใช้บนอะไร, หน้าบันทึกชนกันใช้แบบไหน, มีธีมสว่างไหม, Title เริ่มต้นคืออะไร, ความสว่างของข้อความเนื้อหาในธีมมืด

## Resolution

ยืนยันโดยผู้ใช้

- แพลตฟอร์ม: **มือถือและคอมพิวเตอร์** (ผู้ใช้ตอบสั้นๆ ยังไม่ได้ระบุว่าเป็นเว็บที่ปรับตามขนาดจอ หรือแอปเนทีฟ ดูข้อสงสัยด้านล่าง)
- หน้าบันทึกชนกัน (007): ใช้ **Variant A Side-by-side** (เทียบสองฝั่ง) เหมือนหน้าตรวจผล AI
- **ไม่มีธีมสว่าง** ธีมมืดเท่านั้น
- Title เริ่มต้น: **"Untitled"**
- ข้อความเนื้อหาในธีมมืด: **ไม่ลดความสว่าง** คงตามที่ prototype 017 ใช้

ข้อสงสัยที่เกิดจากคำตอบเหล่านี้ (ยังไม่ได้ตัดสิน):
- มือถือคือเว็บบนเบราว์เซอร์มือถือ (ปรับตามขนาดจอ) หรือแอปเนทีฟ กระทบเลือกเทคโนโลยีและ API
- Layout ที่เลือกไว้ใน 017 (แถบข้าง ~300px, เนื้อหา ~600px ชิดซ้าย) ใช้กับจอกว้าง บนมือถือต้องมี layout แยก (เช่น แถบข้างเป็นลิ้นชักที่เปิดปิดได้) ยังไม่ได้ออกแบบ
- Side-by-side แคบเกินไปบนมือถือ ต้องมีทางสำรองสำหรับหน้าตรวจผล AI และหน้าบันทึกชนกัน (เช่น แสดงสองฝั่งต่อกันในแนวตั้ง หรือสลับฝั่ง)
- ลากย้าย Note ใน Tree ใช้บนจอสัมผัสยาก ต้องมีวิธีย้ายแบบไม่ลาก (เมนู "ย้ายไปไว้ใต้" ที่มีอยู่แล้วใน prototype 017 ใช้ได้)
- เมนู `/` บนแป้นพิมพ์มือถือ ต้องดูว่าพิมพ์และเลือกคำสั่งสะดวกไหม

- (อัปเดตภายหลัง 2026-10-18) ตัดสินแล้ว: **Responsive Web เป็นแพลตฟอร์มหลักในระยะแรก** ออกแบบและทดสอบทั้งคอมพิวเตอร์และมือถือ มือถือต้องเขียนและใช้เมนู `/` ได้จริง Native App เป็นทางเลือกในอนาคต ไม่อยู่ในขอบเขตระยะนี้ ข้อสงสัยแรกในรายการข้างบน (เว็บหรือเนทีฟ) จึงตอบแล้ว ข้อสงสัยเรื่อง layout มือถือและแป้นพิมพ์มือถือยังต้องทดสอบ (ticket 022)
