## Question

กฎของ Share Link แบบดูอย่างเดียว (§16): Link แชร์เฉพาะ Note เดียวหรือรวม Child ด้วย, Reference Card ใน Note ที่แชร์พาไปดู Note อื่นได้ไหมถ้า Note นั้นไม่ได้แชร์, ผู้รับต้อง Login ไหม, เพิกถอน Link ได้ไหม, Link หมดอายุไหม, และเมื่อ Note ที่แชร์ถูกย้าย/Merge/ลบ Link ยังใช้ได้ไหม

ยืนยันแล้วโดยผู้ใช้: ผู้รับดูได้อย่างเดียว ไม่แก้ไข

Options เดิมก่อนตัดสินใจ (เป็นข้อเสนอ ไม่ใช่ผลลัพธ์ ผลลัพธ์อยู่ใน Resolution):
- ผู้รับไม่ต้อง Login เพิกถอนได้ ไม่มีวันหมดอายุ
- แชร์ได้ทั้งแบบ Note เดียวและแบบรวม Child (ให้เจ้าของเลือก)
- Reference Card ไปยัง Note ที่ไม่ได้แชร์แสดงเป็นการ์ดที่เปิดไม่ได้

## Resolution

ยืนยันโดยผู้ใช้

- ผู้รับดูได้อย่างเดียว ไม่แก้ไข
- แชร์ Note นั้นพร้อมลูกหลานทั้งกิ่งเสมอ ไม่มีตัวเลือกแชร์เดี่ยว
- ผู้แชร์เลือกตอนสร้าง Link: "จำกัดด้วย email" หรือ "ใครมี Link ก็ดูได้"
- จำกัดด้วย email: ผู้รับต้อง Login ด้วยบัญชี Jod ที่ email ตรงกันและยืนยันแล้ว (ส่งต่อ ticket 014)
- Reference Card ใน Note ที่แชร์: ผู้รับกดเปิด Note ที่การ์ดชี้ได้ รวมลูกหลานทั้งกิ่งของ Note นั้น (ผลที่ตามมา: ผู้รับตามการ์ดต่อไปได้เรื่อยๆ ผู้แชร์ต้องรู้เองว่าการ์ดในกิ่งที่แชร์จะพาไปเห็นอะไร) (ตัดสินแล้ว)
- ผู้แชร์เพิกถอน Link ได้ทุกเมื่อ และตั้งวันหมดอายุได้ (ค่าเริ่มต้นไม่หมดอายุ) หมดอายุ = เหมือนถูกเพิกถอน
- Note ถูกย้าย: Link ใช้ได้ต่อ / ถูกลบ (Trash): ใช้ไม่ได้ กู้แล้วใช้ได้อีก / ถูก Merge: Link ใช้ไม่ได้
