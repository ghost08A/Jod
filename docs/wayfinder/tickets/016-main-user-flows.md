## Question

ร้อยกฎที่ตัดสินแล้วเป็น User Flow หลัก และหาช่องว่าง: จดโน้ต → จัดวาง (ผ่าน Save / AI / ลากเอง) → ค้นหา → ลบ/กู้ → แชร์ แต่ละ Flow ไล่ทีละขั้นว่าผู้ใช้เห็นและทำอะไร มีกรณีขอบ (edge case) ไหนที่กฎเดิมยังไม่ครอบ ถ้ามีให้บันทึกเป็น ticket ใหม่หรือหมอก

Options เดิมก่อนตัดสินใจ (เป็นข้อเสนอ ไม่ใช่ผลลัพธ์ ผลลัพธ์อยู่ใน Resolution):
- เขียนเป็น Flow ใน `docs/wayfinder/flows.md` ให้ผู้ใช้ตรวจ

## Resolution

ผู้ใช้ยืนยัน [flows.md](../flows.md) ว่าตรงกับที่คิด

- ช่องว่าง G1 (ของใหม่เข้ากิ่งที่แชร์อยู่ เช่น ย้ายเข้า, Merge เข้า, สร้างลูก, กู้คืน): ถูกแชร์อัตโนมัติตามกฎ "แชร์ทั้งกิ่ง" โดย Note ใต้กิ่งที่แชร์มีเครื่องหมายบอกชัดว่า "แชร์อยู่ผ่าน Link ของ …" และเตือนก่อนย้าย/Merge เข้าไป
