## Question

เมนู `/` ใน Editor มีคำสั่งอะไรบ้าง และแต่ละคำสั่งหมายถึงอะไร (ใช้สร้าง Block และเชื่อม Note)

## Resolution

ยืนยันโดยผู้ใช้ (ผู้ใช้เป็นคนกำหนดรายการ)

**หมวด 1: ข้อความและโครงสร้าง**
- `/text` ข้อความธรรมดา · `/h1` `/h2` `/h3` หัวข้อระดับ 1-3 · `/bullet` รายการหัวข้อย่อย · `/numbered` รายการเรียงลำดับ · `/todo` รายการ Checkbox · `/quote` ข้อความอ้างอิง · `/divider` เส้นแบ่งเนื้อหา

**หมวด 2: Note และลิงก์**
- `/note` สร้าง Child Note ใหม่ พร้อมแทรก Reference Card ของ Note ใหม่ที่ตำแหน่งปัจจุบัน
- `/reference` ค้นหา Note ที่มีอยู่แล้วและแทรก Reference Card โดยไม่สร้าง Child ใหม่ และไม่เปลี่ยน Parent ของ Note ที่ถูกอ้างอิง
- `/link` สร้าง Link ไปยัง URL ภายนอก (ไม่ใช่การเชื่อม Note ภายใน Jod)
- ข้อกำหนด: `/note` กับ `/reference` ต้องแยกความหมายชัด `/note` สร้างทั้งความสัมพันธ์ Parent-Child และ Reference Card ซึ่งเป็นคนละแนวคิด (ตรงกับ ticket 001)

**หมวด 3: เนื้อหาพิเศษ**
- `/code` Code Block · `/image` แทรกรูปภาพ · `/file` แนบไฟล์ · `/toggle` เนื้อหาที่พับและขยายได้ · `/callout` ข้อความเน้นสำคัญ

สิ่งที่ต่างจากที่ตัดสินไว้ก่อนหน้า (บันทึกไว้ให้ชัด ไม่ได้ถือว่าเป็นการเปลี่ยนกฎเดิมโดยอัตโนมัติ):
- Heading มี 3 ระดับ (เดิมไม่ได้ระบุระดับ)
- **Block ชนิดใหม่ 2 อย่าง** ที่ยังไม่อยู่ในรายการ Block เดิม: รูปภาพ (`/image`) และ Callout (`/callout`)
- คำสั่งใหม่ `/reference` (เดิมการ์ดเกิดจาก `/note` เท่านั้น)

ข้อสงสัยที่เกิดขึ้น (ยังไม่ได้ตัดสิน):
- รูปภาพ (`/image`) เป็น Block ชนิดแยก หรือเป็นไฟล์แนบ (`/file`) ที่แสดงเป็นภาพ ผลต่อกฎไฟล์ (เป็นของ Note เดียว ตามไปกับ Note)
- รูปภาพและ Callout อยู่ในรายการ Block ที่ AI ห้ามแตะ (013) หรือไม่ ตอนนี้ห้ามแตะ = Reference Card, ไฟล์, Code, Link
- `/note` ควรสร้าง Note ทันทีหรือเปิดขั้นตอนให้ตั้งชื่อก่อน: กฎปัจจุบันคือสร้างทันทีไม่ถูกลบเอง (002) ให้ทดลองใน prototype (ticket 021) ในฐานะข้อเสนอเท่านั้น ห้ามเปลี่ยนกฎเดิมจนกว่าผู้ใช้ตัดสิน
