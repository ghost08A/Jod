# Main user flows (confirmed)

สรุปจากกฎที่ตัดสินแล้วใน ticket 001-015 ผู้ใช้ยืนยันแล้ว (ticket 016)

## 1. จดโน้ต
1. ผู้ใช้อยู่หน้าแรก กดปุ่ม New note (ปุ่มเดียว ไม่มีในหน้า Note)
2. เขียนได้ทันที ไม่ต้องตั้งชื่อ (Title เริ่มต้นเป็นข้อความคงที่) Autosave ตลอด
3. กด Save แล้วเลือก 1 ใน 3: ให้ AI จัดให้ / เป็นแม่ใหม่ (Root note) / Unplaced
4. ปิดโดยไม่เลือก = Unplaced / ว่างเปล่าและ Title เดิม = ลบถาวร
- ภายใน Note: พิมพ์ `/Note` = สร้างลูกพร้อมการ์ดทันที ไม่มี Save และไม่ถูกลบอัตโนมัติแม้ว่าง

## 2. จัดวาง
1. เปิด "รอจัดวาง" เห็น Unplaced note (มีเครื่องหมายถ้ามี Suggestion)
2. วิธีจัด: ลาก/Move เอง, หรือกดให้ AI เสนอ (ตัวเดียว จาก Note ที่มีอยู่)
3. ยืนยัน = ย้ายทันที / ปฏิเสธ = ยังอยู่ ไม่เสนอที่เดิมซ้ำ
4. ย้ายไปที่ไหนก็ย้ายทั้งกิ่ง ห้ามเข้าลูกหลานตัวเอง

## 3. ค้นหา
ค้นชื่อ+เนื้อหา (ไม่ค้น Context, ไม่รวม Trash) กรองตาม Parent รวมทั้งกิ่ง

## 4. ลบ / กู้ / Merge
- ลบ: เลือกทั้งกิ่ง (ค่าเริ่มต้น) หรือเฉพาะ Note นี้ → Trash (ดูอย่างเดียว)
- กู้: กู้ทั้งกิ่ง หรือลูกเดี่ยว (→ Unplaced) / ลบถาวรผู้ใช้สั่งเอง
- Merge: เลือกปลายทาง ต่อเนื้อหา Child ตามไป ย้อนไม่ได้ การ์ดเก่ายังเปิดได้ผ่าน Alias

## 5. แชร์
1. ต้องยืนยัน email แล้ว สร้าง Link ที่ Note → แชร์ Note+ลูกหลานทั้งกิ่ง ดูอย่างเดียว
2. เลือก "จำกัดด้วย email" (ผู้รับ Login+ยืนยัน) หรือ "ใครมี Link ก็ดูได้" ตั้งหมดอายุได้
3. เพิกถอนได้ทุกเมื่อ / Note ถูกลบหรือ Merge = Link ใช้ไม่ได้
4. ผู้รับกดการ์ดใน Note ที่แชร์ได้ เปิด Note ปลายทางพร้อมลูกหลานทั้งกิ่ง

## ช่องว่างที่พบ
- G1 (ตัดสินแล้ว): ของใหม่เข้ามาในกิ่งที่แชร์อยู่ถูกแชร์อัตโนมัติ มีเครื่องหมาย "แชร์อยู่ผ่าน Link ของ …" และเตือนก่อนย้าย/Merge เข้า
