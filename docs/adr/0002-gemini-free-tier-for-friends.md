# AI ใช้ Gemini ตัวฟรีกับกลุ่มเพื่อน และรับเงื่อนไขของ Google ไว้

Jod ใช้กับกลุ่มเพื่อน ผู้ใช้ตัดสินใจใช้ Gemini API รุ่น `gemini-3.5-flash-lite` แบบตัวฟรี (ตรวจ 2026-10-18: รุ่นนี้ Stable และมีตัวฟรี) เงื่อนไขของ Google สำหรับบริการแบบไม่เสียเงิน (ai.google.dev/gemini-api/terms) ระบุว่า Google ใช้เนื้อหาที่ส่งและคำตอบเพื่อปรับปรุงผลิตภัณฑ์ ผู้ตรวจสอบที่เป็นคนอาจอ่านได้ ห้ามส่งข้อมูลส่วนบุคคลหรือความลับ และผู้ให้บริการแก่ผู้ใช้ใน EEA สวิตเซอร์แลนด์ สหราชอาณาจักร ต้องใช้บริการแบบเสียเงินเท่านั้น ผู้ใช้ตัดสินใจ **ไม่เพิ่มคำเตือนเรื่อง Google ไม่ขอความยินยอมเพิ่ม และไม่ห้ามตามภูมิภาค** เพราะใช้กับเพื่อน ส่วนข้อความแจ้งครั้งแรกตาม ticket 012 (ส่งอะไรออกไป) คงเดิม

## Consequences

- ถ้าเปิดให้คนนอกกลุ่มเพื่อน หรือมีผู้ใช้ใน EEA/สวิตเซอร์แลนด์/สหราชอาณาจักร ต้องทบทวนการตัดสินใจนี้ (ย้ายไปบริการเสียเงิน และแก้คำเตือน)
- โควตาตัวฟรีไม่คงที่ (ตรวจได้ในหน้า AI Studio ของโปรเจกต์) ฟีเจอร์ AI อาจใช้ไม่ได้ชั่วคราว ให้ทำตามกฎใน ticket 015 (Note ปลอดภัยเสมอ แจ้งผู้ใช้ ลองใหม่ได้)
- AI เรียกผ่าน Interface ฝั่ง Service เพื่อสลับผู้ให้บริการหรือรุ่นได้
- คีย์ไม่อยู่ในโค้ดหรือ git
