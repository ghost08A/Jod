# ส่งอีเมลผ่าน IEmailService ด้วย SMTP และใช้ Mailpit ไม่มีบริการส่งอีเมลจริง

Jod ไม่มีงบสำหรับบริการส่งอีเมลทั้งตอนนี้และอนาคต และไม่ต้องส่งถึงกล่องจดหมายจริงของผู้ใช้ ตัดสินเมื่อ 2026-10-19 Service ส่งอีเมลผ่าน `IEmailService` (ประกาศใน `Jod.Domain/Interfaces` ทำงานใน `Jod.Service` ผ่าน SMTP) ส่วนปลายทางคือ Mailpit บน Docker ไม่ออกแบบเผื่อสลับผู้ให้บริการภายนอก ไม่ซื้อโดเมน

## ข้อจำกัด

1. Mailpit ไม่ใช่บริการส่งอีเมลจริง แค่รับและเก็บอีเมลไว้ในหน้าเว็บของมันเอง ผู้ใช้จึงไม่ได้รับอีเมลในกล่องของตนเอง
2. คนที่เปิด Mailpit ได้เห็นลิงก์ของทุกคน (รวมลิงก์รีเซ็ตรหัสผ่าน ซึ่งยึดบัญชีได้) ผู้ดูแลจึงเป็นผู้ที่ต้องเชื่อใจ และยึดบัญชีใครก็ได้ในทางเทคนิค
3. "ยืนยันอีเมลแล้ว" หมายถึง "ผู้ดูแลส่งลิงก์ให้เจ้าของแล้วเจ้าของคลิก" ไม่ใช่การพิสูจน์ว่าเป็นเจ้าของกล่องจดหมาย การสร้าง Share Link และ Share Link แบบจำกัดด้วยอีเมลจึงพึ่งความน่าเชื่อถือของผู้ดูแล
4. วิธีนี้ใช้มือทำทีละราย รองรับได้เฉพาะกลุ่มเพื่อนขนาดเล็ก ไม่ถึงเป้าหมายหลักพันบัญชี ถ้ากลุ่มโตต้องทบทวน (OQ-6)

## ข้อบังคับของระบบ

- Mailpit ต้องไม่เปิดสู่อินเทอร์เน็ต ต้องตั้งรหัสผ่านเข้าหน้าเว็บ และตั้งให้ลบอีเมลเก่าอัตโนมัติในเวลาสั้น (ลิงก์หมดอายุเองอยู่แล้ว)
- หน้าเว็บของ Jod ไม่แสดงลิงก์ให้ผู้ขอเห็นเด็ดขาด และไม่บอกว่าอีเมลนั้นมีบัญชีหรือไม่ (ตอบเหมือนกันทุกกรณี)
- ขอลิงก์ใหม่สำหรับอีเมลเดิม ทำให้ลิงก์เก่าของอีเมลนั้นใช้ไม่ได้ทันที
- รีเซ็ตรหัสผ่านสำเร็จ ต้องเพิกถอน Refresh token ทั้งหมดของบัญชีนั้น (ตาม ADR 0006)

## ขั้นตอนผู้ดูแลก่อนส่งลิงก์ต่อ (นโยบายการใช้งาน ไม่ใช่โค้ด)

1. ส่งเฉพาะลิงก์ที่ตรงกับอีเมลซึ่งผู้ดูแลรู้ว่าเป็นของคนนั้นอยู่แล้ว ถ้าเป็นอีเมลที่ไม่รู้ว่าเป็นของใคร ไม่ส่ง
2. ลิงก์ยืนยันอีเมล: ส่งต่อให้เจ้าของทางแชทที่ผู้ดูแลมีกับเขาอยู่ก่อนแล้ว
3. ลิงก์รีเซ็ตรหัสผ่าน: ต้องยืนยันผ่านอีกช่องทางหนึ่งที่ต่างจากแชทที่ขอมา (โทรหรือเจอตัว หรือแชทอีกบัญชีที่ผู้ดูแลเคยคุยด้วยมานานก่อนหน้า) แล้วส่งต่อทางช่องทางที่ยืนยันแล้วเท่านั้น
4. ส่งทีละลิงก์ให้ผู้ขอคนเดียว ไม่โพสต์ในแชทกลุ่ม ไม่ส่งภาพหน้าจอ Mailpit และไม่ส่งลิงก์ที่เกินอายุ
5. ถ้าไม่มั่นใจตัวตน ปฏิเสธไว้ก่อน

## ความเสี่ยงที่ยอมรับ

ถ้าบัญชีแชทของเพื่อนถูกยึดหรือมีคนแอบอ้าง และการยืนยันผ่านอีกช่องทางไม่ได้ผล ลิงก์อาจถึงคนผิด ไม่มีวิธีราคาถูกที่พิสูจน์ความเป็นเจ้าของบัญชีได้ ขั้นตอนข้างบนลดความเสี่ยงแต่ไม่ขจัด

## เงื่อนไขก่อนเปิดให้เพื่อนใช้ผ่านเซิร์ฟเวอร์

ต้องมีขั้นตอนผู้ดูแลข้างบนเป็นลายลักษณ์อักษร และตั้งค่า Mailpit ตามข้อบังคับของระบบครบ
