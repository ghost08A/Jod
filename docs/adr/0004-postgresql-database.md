# ใช้ PostgreSQL เป็นฐานข้อมูล

ฐานข้อมูลของ Jod คือ PostgreSQL (รันบน Docker, ต่อผ่าน EF Core ใน `Jod.Service`) ตัดสินเมื่อ 2026-10-19 เพราะเป็นตัวที่ฟรี รองรับ `jsonb` สำหรับเก็บเนื้อหา Block (ADR 0005), มี recursive query ไว้ไล่ Tree และมีส่วนเสริมค้นข้อความแบบไม่ต้องตัดคำ (`pg_trgm`) ซึ่งสำคัญกับภาษาไทย ย้ายไปตัวอื่นทีหลังต้องย้ายทั้งข้อมูลและ query จึงถือเป็นข้อผูกมัดระดับระบบ

## Considered Options

- SQL Server: เข้ากับ .NET แต่ตัวฟรีมีข้อจำกัดขนาดและการใช้งานจริง และค้นภาษาไทยต้องหาทางเอง
- SQLite: ง่ายสุด แต่เขียนพร้อมกันหลายคนได้จำกัด สำรองข้อมูลและขยายทีหลังลำบาก ขัดกับเป้าหมาย "เลือกสิ่งที่ขยายทีหลังได้" (product-spec หัวข้อ 15)

## Consequences

- โครง Tree เก็บแบบแม่-ลูกตรงๆ (Parent + ลำดับในหมู่พี่น้อง) ไล่ลูกหลานและตรวจ "ห้ามย้ายเข้าลูกหลาน" ด้วย recursive query ไม่ใช้ `ltree` หรือตารางบรรพบุรุษ-ลูกหลาน เพราะที่ขนาดหลักหมื่น Note ต่อบัญชีไม่คุ้มความซับซ้อน
- Alias ของ Note ที่ถูก Merge เก็บในตารางแยก ตามต่อทีละขั้นถึงปลายทาง
- วิธีค้นหาภาษาไทยยังไม่ตัดสิน (หัวข้อค้นหาใน ticket 023)
