# ใช้ PostgreSQL เป็นฐานข้อมูล

ฐานข้อมูลของ Jod คือ PostgreSQL (รันบน Docker, ต่อผ่าน EF Core ใน `Jod.Service`) ตัดสินเมื่อ 2026-10-19 เพราะเป็นตัวที่ฟรี รองรับ `jsonb` สำหรับเก็บเนื้อหา Block (ADR 0005), มี recursive query ไว้ไล่ Tree และมีส่วนเสริมค้นข้อความแบบไม่ต้องตัดคำ (`pg_trgm`) ซึ่งสำคัญกับภาษาไทย ย้ายไปตัวอื่นทีหลังต้องย้ายทั้งข้อมูลและ query จึงถือเป็นข้อผูกมัดระดับระบบ

## Considered Options

- SQL Server: เข้ากับ .NET แต่ตัวฟรีมีข้อจำกัดขนาดและการใช้งานจริง และค้นภาษาไทยต้องหาทางเอง
- SQLite: ง่ายสุด แต่เขียนพร้อมกันหลายคนได้จำกัด สำรองข้อมูลและขยายทีหลังลำบาก ขัดกับเป้าหมาย "เลือกสิ่งที่ขยายทีหลังได้" (product-spec หัวข้อ 15)

## Consequences

- โครง Tree เก็บแบบแม่-ลูกตรงๆ (Parent + ลำดับในหมู่พี่น้อง) ไล่ลูกหลานและตรวจ "ห้ามย้ายเข้าลูกหลาน" ด้วย recursive query ไม่ใช้ `ltree` หรือตารางบรรพบุรุษ-ลูกหลาน เพราะที่ขนาดหลักหมื่น Note ต่อบัญชีไม่คุ้มความซับซ้อน
- Alias ของ Note ที่ถูก Merge เก็บในตารางแยก ตามต่อทีละขั้นถึงปลายทาง
- วิธีค้นหาภาษาไทยยังไม่ตัดสิน (หัวข้อค้นหาใน ticket 023)

## [เงื่อนไขก่อน Production] การสำรองและกู้คืนฐานข้อมูล

เพิ่มเมื่อ 2026-10-19 จากการตรวจเงื่อนไขก่อน Production ของ ADR 0001 และ 0008 ซึ่งครอบคลุมเฉพาะที่เก็บไฟล์ ไม่มีที่ไหนกำหนดการสำรองฐานข้อมูล ทั้งที่เนื้อหา Note, โครง Tree, บัญชี, Share Link และตารางไฟล์อ้างอิงอยู่ในฐานข้อมูลนี้ทั้งหมด ก่อนเปิดให้เพื่อนใช้ผ่านเซิร์ฟเวอร์ต้องมี:

1. ขั้นตอนสำรองฐานข้อมูลที่เขียนเป็นลายลักษณ์อักษร และทดสอบกู้คืนบนเครื่องว่างแล้วพบว่าข้อมูลครบ
2. ตัดสินใจเรื่องที่ยังไม่ได้ตัดสิน: วิธีสำรอง, ความถี่, เก็บกี่ชุดและนานเท่าไร, เก็บไว้ที่ไหน (ต้องไม่ใช่ดิสก์เดียวกับฐานข้อมูล), การป้องกันไฟล์สำรอง (ไฟล์สำรองมีเนื้อหา Note ทั้งหมด) และใครกู้ได้
3. กำหนดลำดับและวิธีตรวจความสอดคล้องกับการสำรองที่เก็บไฟล์ (ADR 0001, 0008) เพราะฐานข้อมูลกับที่เก็บไฟล์สำรองคนละเวลากัน อาจเกิดกรณีฐานข้อมูลที่กู้คืนอ้างถึงไฟล์ที่ไม่มีในที่เก็บ หรือที่เก็บมีไฟล์ที่ฐานข้อมูลไม่รู้จัก (ไฟล์ที่ไม่มีผู้อ้างถึงจะถูกงานเก็บกวาดจัดการ แต่ไฟล์ที่หายไปกู้ไม่ได้)

## [ยังไม่ได้ทดสอบ]

ยังไม่ได้เลือกเครื่องมือสำรอง และยังไม่ได้ทดสอบการสำรองหรือกู้คืนฐานข้อมูลใดๆ ผลทดสอบสำรอง/กู้คืนที่มีอยู่ใน ADR 0001 และ 0008 เป็นของที่เก็บไฟล์เท่านั้น
